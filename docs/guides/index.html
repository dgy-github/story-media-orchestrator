零门槛启动

内置 FFmpeg，免配 PATH

装 pip install -e ".[preview,mcp]" 即自带 imageio-ffmpeg，无 ffprobe 也能跑通母带校验。

单镜精准止损

输入指纹防脏缓存

修改首帧、提示词或音轨只重做受影响的单镜，未改动镜头和配音全部复用，大幅省钱。

双通道接入

CLI 无人值守 + MCP 接管

日常全自动批跑走 CLI，疑难镜头直接让 Antigravity / Codex / Cursor 通过 MCP 看图修片。

10 分钟零门槛上手（无需任何 API Key）

按顺序复制下面 4 条命令，即可在本地跑出第一条带字幕的 MP4 成片与剪映工程草稿。

1

安装依赖并运行环境自检

推荐 Python 3.11+。preview 自带 FFmpeg 二进制，mcp 安装视觉拆帧与 MCP 网关依赖。

pip install -e ".[preview,mcp]"
python -m story_media_orchestrator.cli doctor
2

用一句话创建短剧工程

系统自动切分镜头并生成 demo-ep01/project.json 状态机。

python -m story_media_orchestrator.cli create demo-ep01 "林雾撑伞走过雨夜长街。她停在钟楼门前，抬头望向亮着暖光的阁楼。"
3

零成本跑通预览版成片（Preview 模式）

不调用付费 API，直接合成可播放 MP4（Windows 下可把 silent 改为 windows 启用本地语音）。

python -m story_media_orchestrator.cli run demo-ep01 --mode preview --real-preview --tts-source silent --auto
4

一键导出剪映草稿

把生成的草稿文件夹复制到剪映草稿目录，即可继续加配乐、特效或精调切点。

python -m story_media_orchestrator.cli export-jianying demo-ep01
关于本地环境依赖： 日常预览、切帧、MCP 审片和 verify-master 校验只需 pip install -e ".[preview,mcp]"（已内置 ffmpeg 且支持无 ffprobe 回退）。仅当你需要使用对白语音识别审计 audit-speech 时，再额外安装 pip install -e ".[asr]"。

MCP 多 Agent 并发协同架构

直接把本工程作为 MCP Server 挂进 Antigravity / Codex / Cursor，复用客户端里已有的多模态大模型看图、生图、注入素材与提交质检裁决。

方式一：单窗口精简接入（推荐新手）

用 --profile core 只暴露 16 个核心素材与审片接口，上下文更清爽：

python -m story_media_orchestrator.cli mcp --transport streamable-http --host 127.0.0.1 --port 8780 --profile core

方式二：双端口专职并发（生图 + 审片分离）

一个窗口只管生图注入，另一个窗口只管看片裁决，互不撞锁：

python -m story_media_orchestrator.cli mcp --transport streamable-http --port 8781 --profile producer
python -m story_media_orchestrator.cli mcp --transport streamable-http --port 8782 --profile critic

直接复制给 AI 的审片指令模板

请连接 story-media-supervisor，先调用 story_get_pipeline_snapshot 查看 ./demo-ep01 总览，再用 story_claim_takeover(role="critic") 拿锁。
对未通过镜头逐个调用 story_inspect_shot_multimodal 查看首帧、2x2 诊断格和 8 帧条带，按角色一致性、动作连贯性、无伪字幕、音画同步提交 story_submit_quality_verdict，完成后释放租约。

分级仲裁漏斗：先零费用硬门，再按需升级二审

不让大模型为黑帧或残缺文件浪费 token，也不让每镜都重复调用多个模型。
