# 验证记录与能力边界

更新：2026-09-08。这里区分真实模型验证、自动化测试和待验证功能。

## 真实媒体链路

在全新项目中完成两张阿里云图片、两段 Wan 视频及最终 MP4 合成。成片为 10.72 秒、1280×720；完整解码与浏览器从头到尾播放通过。

人为触发本地最终合成失败后，旧成片保留。恢复时复用已有图片、音频和视频，素材内容及修改时间未变化，没有新建视频生成请求。[查看实际视频](assets/aliyun-preview.mp4)。

这一结果验证的是两镜头媒体链路，不代表长篇视频、所有模型组合或所有故障都能自动恢复。

## 真实故事链路

沿用原故事模板、DeepSeek 生成与阿里云审核服务，最终完成 17 个任务，输出 6 集、14 个场景和 3 名角色。完整故事包通过最终模型审查，并成功导入本工作台为 80 条分镜。

这次验证中，旧服务曾将底层失败统一变成 HTTP 502，具体原因无法追溯。现已补充安全的错误分类与跨服务传递。另发现 6 万和 18 万 Token 预算不足以完成此次完整流程，调整至 30 万后恢复完成。30 万是当前六集建议值，不是效果、耗时或费用保证；用户保存的预算不会被自动覆盖。

恢复验收显式调用了原工作流的保留产物恢复能力。界面的“取回原任务结果”主要用于查询既有结果，不保证重新启动已经终止的故事任务。模型审查通过不等于人工创作品质验收。

## 自动化验证

- 本仓库：127 项 Python 测试、8 项常规 Rust 测试通过；前端构建通过。
- 浏览器回归：项目名称与路径、刷新保留、模板恢复、任务参数传递、字幕和播放。
- 原故事仓库：Rust 工作区测试与 Clippy、44 项侧车测试、157 项评估工具测试通过；18 项故事表单测试与 Svelte 检查通过。
- 云端生成相关测试中包含模拟服务测试；它们验证请求、缓存和失败处理，不代表真实模型质量。

## 当前限制

- 桌面主要在 Windows 验证，完整 AI 功能需要相邻仓库、Python 环境和模型服务配置。
- ComfyUI / MiniMax H3 路线尚未在此次环境完成真实 GPU 验收。
- Wan 首尾帧路线已有传输契约与恢复测试，此次真实视频样例使用文生视频路线。
- Windows 本地语音可选；此次阿里云视频样例为静音，云端语音未接入。
- 暂停不等于取消已经提交的云端任务，不能承诺供应商立即停止或退款。
- 提交结果未知时保留任务线索，不自动重复提交；仍需确认供应商状态后决定下一步。
- 人物与画面连续性仍受模型和提示词影响，需要人工挑选、审查与返工。
